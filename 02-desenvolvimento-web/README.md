# Estudos de Desenvolvimento Web

Ambiente dedicado ao aprendizado de tecnologias front-end e ao desenvolvimento web.

O conteúdo está dividido nos principais pilares necessários para este tipo de desenvolvimento, sendo eles:
    HTML5: Estruturação do conteúdo
    CSS3: Layout e estilização da página
    JavaScript: Comportamento e Interatividade
    Projetos práticos: Transformando o aprendizado em ideias tangíveis.

A finalidade do material é apresentar a progressão dos estudos, disponibilizando todas as etapas de aprendizado do cenário, com o objetivo de consolidar todo o conteúdo e transformá-los em projetos práticos.
