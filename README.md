# Jornada da Programação | Processo de desenvolvimento das habilidades através dos estudos.

  Sou estudante de TADS, a princípio focado em BackEnd. Neste repositório, você vai encontrar uma organizada compilação do meu processo de aprendizagem.
  Todo o material relevante que desenvolvo através das aulas da Universidade e dos cursos realizados em plataformas de ensino, será disponibilizado neste ambiente.

  A finalidade deste conjunto é, apresentar as etapas do processo do meu desenvolvimento, tanto como aluno, como profissional. Ou seja, deixar perceptível através dos materiais disponibilizados, o contraste que vai se criando conforme absorvo os conceitos aprendidos.
  
  Para isto o processo apresentado será, desde os princípios básicos da programação até a consolidação de uma lógica firme e eficaz.
