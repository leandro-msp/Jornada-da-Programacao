    - Desenvolvimento para Internet:
        Área da computação responsável pela criaçõ de sites, sistemas e aplicação que funcionam por meio da Web, acessaos via navegadores como Google Chrome, Microsoft Edge e Safari.

        Exemplos: Sites Institucionais, E-Commerce, Sistemas Web e Aplicações Web

        Como a Internet Funciona:
            A Web funciona baseada em modelo de comunicaçõ entre dois elementos: Cliente(A máquina onde está o browser que o usuário está) e Servidor(computador remoto que armazena os arquivos e sistemas do site), esse se processo é nomeado como requisição e resposta.
        
        Montagem de páginas, e conexão entre elas.

    FRONTEND: É a parte do sistema com a qual o usuário interage diretamente.
            Interface Gŕafica
            Experiência do usuário
            Layout e design

            Tech's: HTML -> Estrutura do conteúdo
                    CSS -> EStilo e layout
                    JavaScript: comportamento e interatividade
    
    BACKEND: Processo Lógico de funcionamento do sistema(bastidores)
                Regras de Negócio
                Processamento de dados
                Comunicação com o Banco de dados
                Autenticação e Segurança

                Exemplos: PHP, JAVA, PHYTON, NODE.js, Banco de Dados(MySQL, PostgreSQL, MongoDB)

    - Introdução ao HTML
        HTML ( Hyper Text Markup Langague) é uma linguagem de Marcação de Hipertexto utilizada para criação de páginas web.
        Ela é responsável em criar a estrutura da página.
        O Navegador vai interpretar essa linguagem e seus comandos e traduzir isso em uma página web.
